# 饰品驿站助手 1.0.1 版本说明

> 2026-11-08 · Windows x64 · NSIS 当前用户安装 · **未签名** · 可覆盖安装 1.0.0，业务数据保留

## 变化

- **三层筛选选择器**：每行条件改为「大类 → 子类」级联多选 + 皮肤多选。大类为刀、手套、步枪、狙击步枪、手枪、微型冲锋枪、霰弹枪、机枪；勾选整个大类即「任意××」。皮肤可从常见名称中选，也可直接输入。
- **行内多选**：同一行内的类别取任一、皮肤取任一，且须由同一件饰品满足；行与行之间仍要求同时满足。
- **内置常用方案**「四刀 + 手套 + AK/M4A1/USP/格洛克」：蝴蝶刀/爪子刀/锯齿爪刀/M9 刺刀之一 + 任意手套 + AK-47 + M4A1 消音版 + USP 消音版 + 格洛克 18 型。首次打开方案列表时加入，可改名、覆盖、删除，删除后不再自动加回。
- **筛选更省请求**：先取候选最少的行，候选已足够少时不再翻页常见武器（如 AK-47），由完整库存确认把关，结果不变。

## 修复

- M4A1：平台大多写作「M4A1消音版」，1.0.0 只认「M4A1 消音型」，会漏掉大部分账号。
- AWP、SSG 08 等属于「狙击步枪」大类，1.0.0 的大类列表中缺失。
- 格洛克、USP 等带空格与不带空格的写法统一识别，搜索关键词不再因空格漏掉候选。

## 兼容

- 1.0.0 保存的常用方案读取时自动转换为新格式，无需重建。

## 已知限制

沿用 [1.0.0 版本说明](版本说明-1.0.0.md) 的已知限制；Windows 10 22H2 矩阵仍未执行。
