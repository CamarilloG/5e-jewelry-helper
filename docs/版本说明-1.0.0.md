# 饰品驿站助手 1.0.0 版本说明

> 2026-11-08 · Windows x64 · NSIS 当前用户安装 · **未签名**

## 功能

- **组合筛选**：饰品大类/刀型/武器 + 皮肤名称，同一行由同一件饰品满足，多行取交集；叠加六种租期与价格区间、仅可用券；完整库存确认、匹配度排序、卡片/紧凑列表、可停止/继续。
- **账号详情**：六种租期价格（包时段标注北京时间窗口与可用星期）、完整库存（全部/仅命中）、就地下单参数与报价。
- **常用方案**：保存、覆盖、另存、重命名、删除、一键套用。
- **收藏监测**：与平台收藏双向同步（只增不删）、单条监测开关、默认 60 秒检查、变为可租时 Windows 通知（同轮多个合并），托盘角标。
- **一键出码**：每个收藏可设下单预设；首次确认协议后一键创建订单并展示平台付款码与倒计时；自动选择最优惠可用券；取消、超时、结果不明时的释放与恢复流程。
- **设置**：登录态、监测、通知、默认预设、收藏同步与已移除恢复、请求速率与缓存、关闭行为、诊断导出、关于与检查更新。

## 安全与边界

- 凭证只在本机解析器与主进程内存中使用，只发送给 5E 官方接口；不进入界面、数据库或日志。
- 所有平台请求共用每分钟 30 次的限速队列。
- 不自动锁单/抢单、不代付；创建请求最多发送一次；付款由用户扫码；上号/下号回到 5E 客户端。
- 不后台检查更新、不遥测、不回传数据。

## 已知限制

- 平台接口非公开，可能随时变化；结构异常时会提示“平台接口可能已变更”。
- 只选大类（如“手套”）而不填名称时，需要浏览该租期全部账号并逐个确认库存，耗时较长。
- 精细筛选（图案、磨损、StatTrak、贴纸）与续租出码不在本版本范围。
- 安装包未签名，首次运行可能出现 SmartScreen 提示。
- 发布验收仅在 Windows 11 x64 完成，Windows 10 22H2 矩阵尚未执行。
