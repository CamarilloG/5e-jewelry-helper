# 饰品驿站助手 1.0.3 版本说明

> 2026-11-08 · Windows x64 · NSIS 当前用户安装 · **未签名** · 可覆盖安装 1.0.0 / 1.0.1 / 1.0.2，业务数据保留

本版是前端专项优化，不改变匹配规则、出码、支付和订单状态机。

## 变化

- **结果卡片命中优先、按价值补满**：卡片 4 个饰品位（列表 3 个），命中饰品在前并带「命中」角标，空位用该账号完整库存中未命中的饰品按估价从高到低补齐。主进程随扫描结果新增 `fillItems`，不增加平台请求；未读完整库存的账号只能用平台展示位补齐。
- **详情库存分类切换**：「全部」加账号实际存在的大类及件数，可与「仅命中」和排序叠加。
- **详情下单区吸底**：租期、报价、协议、「一键出码」和风险提示始终可见，上方内容统一滚动，不再嵌套库存滚动条。
- **筛选结果合并滚动**：「已匹配，状态待确认」分组与主结果共用同一滚动区，分组也改为虚拟渲染。
- **结果列表重排**：列宽在 1200 宽下不再塌陷，表头吸顶，放不下时收起「卖点」列。
- **筛选页更紧凑**：卡片高度降低，工具栏压缩，搜索范围说明收进信息图标；条件很多时操作区吸在面板底部。
- **状态文字加深**：徽标描边和圆点沿用规范色，文字改为更易读的深色。

## 修复

- 抽屉拖拽手柄显示为灰色粗条并遮挡正文，现在平时隐藏，悬停、拖动或键盘聚焦时显示。
- 设置页左侧栏高度与页面不齐，现在撑满整列，样式与主导航一致，并默认高亮当前分组。
- 价格填写非数字时只有红框没有说明，现在给出明确提示。
- 收藏、方案、设置加载中不再误显示为空，操作失败统一给出中文提示。
- 数字设置项改为失焦或回车才保存，避免输入过程中保存中间值；清除缓存增加确认和结果提示。
- 卡片支持空格键打开，内部按钮的按键不再误触卡片；补充键盘焦点样式。
- 详情库存按估价排序时，估价缺失的饰品不再排在最前。
- 降低收藏页重渲染开销。

## 已知限制
