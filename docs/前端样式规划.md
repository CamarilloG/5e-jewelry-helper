# 饰品驿站助手 —— 前端样式规划（草稿）

> v0.1 · 2026-11-07 · 依据 [需求文档.md](需求文档.md) 的 MVP 范围（F1 筛选 + F2 收藏监测 + F3 半自动出码）。
> 本文件只定**界面结构与视觉方向**，不涉及技术栈。效果图见 [`ui-mockups/`](ui-mockups/)。
>
> **状态（2026-11-07 用户确认）：前端设计风格已定稿，采用浅色简洁工具风（B）。**
> ⚠️ `ui-mockups/` 中的图片均为 AI 生成的**风格参考**，仅用于示意视觉风格与大致布局，**不代表实际产品功能**；图中的功能、文案、字段、数据与交互细节一律以 [需求文档.md](需求文档.md) 与 [产品文档.md](产品文档.md) 为准。

## 1. 整体形态

- Windows 桌面窗口，默认 1440×900，最小 1200×760；可最小化到系统托盘常驻。
- 三栏布局：**左侧导航栏**（窄，图标+文字）｜**主内容区**｜按需出现的**右侧详情抽屉**。
- 左侧导航四项：`筛选` / `收藏监测` / `常用方案` / `设置`；底部固定显示**登录态与请求状态**（已读取客户端登录态 · 剩余有效天数 · 当前请求速率）。
- 第三方工具：不使用 5E 的 Logo、品牌色与字标，避免被误认为官方产品。

## 2. 页面清单

| 页面 | 对应需求 | 关键内容 |
|---|---|---|
| P1 筛选主页 | F1.1–F1.7 | 左侧条件面板（饰品大类 chips、皮肤名多选、组合条件「同时包含」、价格区间滑块、租期类型）、保存为方案；右侧结果卡片网格 |
| P2 账号详情抽屉 | F1.5、F2.1、F3.3 | 账号状态、租价表、**完整库存**网格（缩略图/名称/外观/估价，命中条件的高亮）、收藏按钮、该账号的下单预设 |
| P3 收藏监测 | F2.1–F2.6 | 收藏列表（状态徽标：可租/租赁中/已下架/预计可租时间）、单条监测开关、上次变化时间、全局监测频率、「一键出码」 |
| P4 一键出码弹窗 | F3.2–F3.5、F4.4 | 付款二维码、实付金额、租期、支付方式、付款倒计时、冻结风险警示条、取消（触发释放）、支付状态 |
| P5 桌面通知 + 托盘 | F2.3、F2.4 | Windows 原生 toast：账号名 + 命中饰品 + 「查看」「一键出码」按钮；托盘菜单：暂停监测 / 打开主窗口 / 退出 |

## 3. 视觉方向

> **已定（2026-11-07，用户选择）：采用 B 浅色简洁工具风。** A 方案保留作参考（日后若做深色模式可复用其配色）。风格参考图（仅供参考，不代表实际功能）：`ui-mockups/B1`–`B5`（筛选主页、账号详情抽屉、收藏监测、一键出码弹窗、通知与托盘）；`A1`–`A5` 为未采用的深色版。

### A. 深色电竞风（未采用）
- 底色 `#0F1115` / 卡片 `#171A21` / 描边 `#262A33`；强调色 **青绿 `#2DD4BF`**（主操作），状态色：可租 `#22C55E`、租赁中 `#F59E0B`、下架 `#6B7280`、风险 `#EF4444`。
- 饰品稀有度沿用 CS2 习惯色作为卡片顶部细色条（隐秘红、保密粉、受限紫、军规蓝、金色刀/手套）。
- 理由：玩家群体熟悉暗色、饰品图在暗底上更出彩、长时间常驻托盘不刺眼。

### B. 浅色简洁工具风（✅ 采用）
- 白底 + 浅灰分区 `#F5F6F8`，强调色靛蓝 `#4F46E5`（主按钮、选中态、价格数字），细描边，信息密度更高、更像效率工具。
- 状态色沿用：可租绿 `#22C55E`、租赁中橙 `#F59E0B`、下架灰 `#6B7280`、风险红 `#EF4444`。
- 命中筛选条件的饰品缩略图左上角加「命中」小标签（见 B1）。
- 理由：表格/数字更易读，截图分享更清爽。

## 4. 组件与交互约定

- **条件 chips**：大类与皮肤名做成可删除的标签；多个条件之间显示「且」连接，强调「交集」是核心卖点。
- **结果卡片**：账号标题、状态徽标、时租/日租价、库存总估值、命中饰品优先展示（其余折叠为 `+N`）、收藏星标。
- **风险表达**：出码相关一律用红/橙警示条 + 明确文字，「一键出码」按钮旁始终注明「将创建订单并占用账号」。
- **请求友好可见化**：底栏显示当前扫描进度与限速状态，让用户理解为什么全量扫描需要时间。
- 字体：Windows 用 `Microsoft YaHei UI` / `Segoe UI`，数字用等宽数字（tabular-nums）。

## 5. 已定事项

- 视觉方案：B 浅色简洁工具风；P2–P5 浅色效果图已出（B2–B5）。
- 租期叫法：统一用平台实测的 6 种——小时租、天租、周租、包早、包午、包夜（B2 图中「包夜」即其中之一）。
- 结果展示：卡片网格 + 紧凑列表两种视图（产品文档 Q3）。
- 托盘与导航角标：显示当前可租的收藏数，为 0 时不显示（产品文档 Q11）。
