# 饰品驿站助手 —— 产品文档（界面与功能模块）

> v0.2 草稿 · 2026-11-07（v0.2：Q1–Q17 已由用户逐项确认，见 §11）
> 上游：[需求文档.md](需求文档.md)（做什么、约束、验收）· [前端样式规划.md](前端样式规划.md)（布局与视觉，已定 B 浅色简洁工具风）。
> 本文件把需求拆到**页面 → 区块 → 组件**，写清每个组件的作用、交互与状态，并附文字线框图。不涉及技术栈、接口字段映射与实现。
> `ui-mockups/` 中的图仅为风格参考，功能与文案以本文件为准。

## 0. 阅读约定

- **需求编号**：括号里的 `F1.3`、`N3` 等指向需求文档条目。
- **决策编号**：`Q1`、`Q2`… 指向 [§11 决策记录](#11-决策记录)，均为已定取舍（用户确认，或经用户授权按 Claude 推荐确定）。
- **租期类型**：统一使用平台实测的 6 种，界面文案如下（全文同）：

  | 文案 | 计量方式 | 说明 |
  |---|---|---|
  | 小时租 | 按小时，可选时长 | |
  | 天租 | 按天，可选时长 | |
  | 周租 | 按周，可选时长 | |
  | 包早 / 包午 / 包夜 | 按时段 | 每个账号可设置在星期几可用；时段起止时间按平台返回的数据显示 |

  合称「时长租」（小时/天/周）与「时段租」（包早/包午/包夜）。某账号某档价格为 0 表示**不支持**该租期。
- **账号状态**（全文同）：`可租`（绿）· `租赁中`（橙，有预计可租时间时一并显示）· `已下架`（灰）· `未知`（灰虚线，检查失败或尚未检查）。

### 2.2 G1 左侧导航栏

| 组件 | 说明 | 交互与状态 |
|---|---|---|
| 产品名 | 工具自有名称与图标，不使用 5E 品牌元素 | 无交互 |
| 导航项 ×4 | 筛选 / 收藏监测 / 常用方案 / 设置，图标+文字 | 点击切换主内容；当前项靛蓝高亮 |
| 收藏监测角标 | 显示「当前可租」的收藏数量（Q11） | 数量为 0 时隐藏 |

切换导航时：P1 的筛选条件与结果**保留**（返回后不重置）；P2 抽屉关闭。

### 2.3 G2 底部状态栏

从左到右三段，均为只读展示，点击跳转对应设置。

| 段 | 内容 | 状态 |
|---|---|---|
| 登录态 | 圆点 + 文案 + 剩余有效天数 | 绿「登录态正常 · 剩 N 天」；红「登录态失效」/「未读取到登录态」。不设「即将过期」提醒（Q12）。点击 → P7 登录态分组 |
| 监测 | 「监测中 可租数/收藏数 · 下次检查倒计时」 | 「监测已暂停」（灰）；「监测异常」（橙，最近一轮有失败）。点击 → P3 |
| 请求 | 「请求 N/分」；有扫描任务时追加「扫描 已确认/候选」 | 触发限速等待时显示「限速等待中 Xs」（N3 可见化）。点击 → P7 请求分组 |

### 2.4 G3 启动与登录态引导

工具不自行登录，只读取本机 5E 客户端的登录态（C1、C2）。启动时自动读取，结果分以下情形：

| 情形 | 判定 | 界面表现 |
|---|---|---|
| 正常 | 读到且未过期，接口可用 | 直接进入 P1 |
| 未检测到客户端 | 找不到客户端数据目录 | 全屏引导页：「未检测到 5E 客户端，请先安装并登录」+「重新检测」+「手动指定目录」 |
| 未登录 | 目录存在但无登录态 | 引导页：「请先在 5E 客户端登录一次」+「我已登录，重新读取」 |
| 已过期 | 有效期已过，或接口返回未登录 | 引导页：「登录态已过期，请在 5E 客户端重新登录」+「重新读取」 |
| 读取失败 | 解析出错 | 引导页：错误摘要（不含凭证内容）+「重试」+「查看帮助」 |

运行中任何接口返回「未登录」时：暂停监测与扫描 → 顶部红色横幅「登录态失效，已暂停监测。请在客户端重新登录后点击重新读取」+ 按钮「重新读取」→ 成功后自动恢复。

**凭证不出现在界面任何位置**，包括错误信息与日志导出（N2）。

### 2.5 G4 全局反馈

| 类型 | 用途 | 规则 |
|---|---|---|
| 轻提示（toast，窗口内右上） | 收藏成功、方案已保存等 | 3 秒自动消失 |
| 横幅（主内容区顶部） | 登录态失效、网络异常、平台接口变更疑似（返回结构异常） | 需手动关闭或问题消除后自动消失 |
| 确认框 | 取消订单、删除方案、取消收藏（有预设时） | 危险操作按钮用红色 |

### 2.6 G5 通用组件

| 组件 | 规格 |
|---|---|
| 状态徽标 | 圆角小标签，按 §0 账号状态配色；租赁中可附「约 HH:mm 可租」 |

### 3.2 区块 A：条件面板

| 组件 | 作用 | 交互与状态 | 需求 |
|---|---|---|---|
| 方案下拉 | 套用已保存方案 | 选中后**覆盖**当前条件并自动开始筛选；当前条件被修改后，下拉显示「方案名（已修改）」 | F1.6 |
| 饰品条件行 | 描述「一件」目标饰品 | 每行含「大类」下拉与「名称」输入，二者至少填一项；**同一行内为同一件饰品**（如 蝴蝶刀 + 多普勒 = 一把多普勒蝴蝶刀） | F1.1、F1.2 |
| 大类下拉 | 选饰品大类 | 可搜索；选项为刀具细类（爪子刀、蝴蝶刀、M9 刺刀…）、手套、各武器类等 | F1.1 |
| 名称输入 | 皮肤/饰品名 | 中文，带联想建议（常见皮肤名）；单行单个名称 | F1.2 |
| 「且」连接符 | 显示行间关系 | 不可交互，强调多行为**交集**：账号库存需同时包含每一行描述的饰品 | F1.3 |
| 删除条件 ✕ | 删除该行 | 仅剩一行时，✕ 改为清空该行 | |
| 添加饰品条件 | 新增一行 | 行数不设上限（Q1）；条件越多确认越久，由 §3.3 进度展示让用户感知 | F1.3 |
| 租期单选 | 选择要按哪种租期筛选与比价 | 6 种单选，默认小时租；只返回支持该租期的账号 | F1.4 |
| 价格区间 | 按所选租期单价过滤 | 两个数字框，可只填一端；单位随租期切换（元/时、元/天、元/周、元/次） | F1.4 |
| 仅可用券 | 只看可用优惠券的账号 | 复选框 | F1.4 |
| 开始筛选 | 发起筛选 | 未填任何饰品条件时也可用（等同原生按租期+价格浏览）；筛选进行中变为「重新筛选」 | |
| 保存为方案 | 存当前条件 | 打开命名框（见 §8.3） | F1.6 |
| 重置 | 清空条件 | 清空条件区，不清空结果区，不二次确认 | |

**条件校验**：价格下限 > 上限时，字段标红并禁用「开始筛选」。

### 3.3 区块 B：筛选执行与进度

原生搜索只支持单关键词，组合条件需工具先取候选、再逐个拉完整库存确认（需求 F1.3 说明）。界面上表现为一个**可见、可中断的扫描任务**：

| 阶段 | 结果区顶部显示 | 说明 |
|---|---|---|
| 取候选 | 「正在获取候选账号…」 | 不确定进度，显示转圈 |
| 确认中 | 「已确认 38 / 候选 120」+ 进度条 +「停止」 | 逐个账号拉取库存，不并发，受请求速率上限约束（Q19）；已确认符合的账号**边确认边出现**在结果区 |
| 完成 | 「共 37 个符合条件的账号」+ 完成时间 | |
| 已停止 | 「已停止 · 已确认 38/120，结果可能不完整」 | 可点「继续」 |
| 限速等待 | 进度条旁「限速等待 Xs」 | 体现 N3 |
| 失败 | 横幅说明原因 +「重试」 | 已出现的结果保留 |

单条件（只填一行）且无需完整库存确认时，可直接返回原生结果，不显示确认阶段。

已扫描过的账号库存在本地缓存，缓存命中的账号直接确认，不再请求。缓存时长在 P7 可调：本次运行 / 1 小时 / 6 小时 / 1 天，**默认 1 小时**（Q2）。

### 3.4 区块 C：结果工具栏

| 组件 | 交互 | 需求 |
|---|---|---|
| 结果计数 | 见 §3.3 | |
| 排序下拉 | 匹配度（默认，有饰品条件时）/ 价格↑ / 价格↓ / 总价值↑ / 总价值↓；价格按当前租期单价 | F1.7 |

| 场景 | 行为 |
|---|---|
| 首次启动 / 每轮检查 | 拉取平台收藏，本地没有的加入本地（来源标「平台」） |
| 在工具内收藏 | 本地新增，同时在平台收藏 |

| 在平台（客户端）取消收藏 | 本地**不删除**，该行标「平台已取消收藏」，操作：「本地也移除」/「重新在平台收藏」 |
| 工具内的「已移除」记录 | 在 P7 可查看并恢复 |

同步写入平台属于对平台的外部写入，仅在用户在工具内执行收藏/取消收藏操作时发生，不做无人触发的写入。

**写回失败**（Q20）：本地操作照常生效；toast「平台收藏同步失败，将在下次同步时重试」；该行标「待同步」，下次同步自动重试，成功后标记消失。

### 6.3 各状态界面

| 状态 | 主体显示 | 按钮 |
|---|---|---|

**窗口约束**：待支付时弹窗不可被主窗口其他操作遮挡；同一时间只允许一个出码弹窗，另一账号再次触发出码时提示「已有待支付订单」。

点击「一键出码」后**不再二次确认**，直接进入预检（Q13）。防误触依靠按钮旁常驻的「将创建订单并占用账号」提示，以及待支付状态下可随时取消释放。
