- **租期类型**：统一使用平台实测的 6 种，界面文案如下（全文同）：

  | 文案 | 计量方式 | 说明 |
  |---|---|---|
  | 小时租 | 按小时，可选时长 | |
  | 天租 | 按天，可选时长 | |
  | 周租 | 按周，可选时长 | |

### 2.4 G3 启动与登录态引导

工具不自行登录，只读取本机 5E 客户端的登录态（C1、C2）。启动时自动读取，结果分以下情形：

| 情形 | 判定 | 界面表现 |
|---|---|---|
| 正常 | 读到且未过期，接口可用 | 直接进入 P1 |
| 未检测到客户端 | 找不到客户端数据目录 | 全屏引导页：「未检测到 5E 客户端，请先安装并登录」+「重新检测」+「手动指定目录」 |
| 未登录 | 目录存在但无登录态 | 引导页：「请先在 5E 客户端登录一次」+「我已登录，重新读取」 |
| 已过期 | 有效期已过，或接口返回未登录 | 引导页：「登录态已过期，请在 5E 客户端重新登录」+「重新读取」 |
| 读取失败 | 解析出错 | 引导页：错误摘要（不含凭证内容）+「重试」+「查看帮助」 |

运行中任何接口返回「未登录」时：暂停监测与扫描 → 顶部红色横幅「登录态失效，已暂停监测。请在客户端重新登录后点击重新读取」+ 按钮「重新读取」→ 成功后自动恢复。

**凭证不出现在界面任何位置**，包括错误信息与日志导出（N2）。

### 3.3 区块 B：筛选执行与进度

原生搜索只支持单关键词，组合条件由工具结合本地缓存、已认证类别搜索证据与完整库存确认流式输出（需求 F1.3 说明，v1.0.3 修订）。界面上表现为一个**可见、可中断的扫描任务**：

| 阶段 | 结果区顶部显示 | 说明 |
|---|---|---|
| 发现与确认中 | 显示发现是否完成、已检查数量、待检查数量、覆盖完整性 +「停止」 | 先推送当前用户范围内的上次结果与本地缓存命中；每取回一页搜索结果立即按账号更新并输出满足全部条件行的账号（首条立即推送，后续 100–300 ms 合并）；发现未结束时不显示固定总量的百分比 |
| 完成 | 「共 N 个符合条件的账号」+ 完成时间 +（若不完整）具体原因标签与恢复按钮 | 区分“已扫描完成”与“覆盖完整”；缺页、重复页、200 页上限截断、提前空页、失败账号未重试等均标注具体原因，提供「重试失败项」入口 |
| 已停止 | 「已停止 · 已检查 X / 待检查 Y，结果不完整」 | 候选阶段与确认阶段均可停止；点「继续」复用已成功分页与已有结果，不从第 1 页重取 |
| 缓存快照提示 | 「候选快照 HH:mm」+「刷新最新」 | 复用 5 分钟搜索分页缓存或上次结果快照时显示快照时间，可点「刷新最新」强制重取平台最新分页 |
| 本地匹配（离线/未登录） | 「本地匹配」按钮与历史/待核验提示 | 离线或登录态未就绪时可单独运行本地匹配，只读当前用户范围历史结果与有效本地缓存，不计为实时可租；无记录时显示「无本地记录」 |
| 限速等待 | 进度条旁「限速等待 Xs」 | 体现 N3 |
| 失败 | 横幅说明原因 +「重试」 | 已出现的结果保留 |

仅含已认证类别、不含皮肤的条件行可通过平台搜索证据直接判定匹配（扫描匹配阶段零库存请求），卡片显示「类别条件匹配，库存详情按需加载」，不显示精确命中件数；同一行含类别和皮肤（同件约束）、含皮肤名称或含未认证/宽关键词时，仍读取完整库存确认。纯租期/价格浏览只在打开详情时加载库存。

已扫描过的账号库存在本地缓存，缓存命中的账号直接复用，不再重复请求。缓存时长在 P7 可调：本次运行 / 1 小时 / 6 小时 / 1 天，**新安装默认 6 小时，旧版升级保留原设置**（Q2，v1.0.3 修订）。

### 3.4 区块 C：结果工具栏

| 组件 | 交互 | 需求 |
|---|---|---|
| 结果计数 | 见 §3.3；“当前可租”数量只统计已确认可租的结果 | |
| 排序下拉 | 价格↑（默认）/ 价格↓ / 匹配度（有饰品条件时）/ 总价值↑ / 总价值↓；价格按当前租期单价 | F1.7 |
| 状态过滤 | 仅可租（默认）/ 全部 / 租赁中 / 已下架 | F1.7 |
| 视图切换 | 卡片网格（默认）/ 紧凑列表（Q3，见 §3.5.1）；选择记忆到下次 | |

「匹配度」= 该账号完整库存中**命中任一饰品条件的饰品件数**，仅对已确认完整库存的结果比较，未读库存的搜索证据匹配排在后面；默认排序为**价格↑**（v1.0.3 修订）。

默认「仅可租」视图下，结果区上方展示独立的折叠分组**「已匹配，状态待确认」**（默认展开），放置已满足筛选条件但正在等待详情确认状态或待复核的账号；状态确认完成后自动移入对应分组。若已有命中账号因状态为租赁中/已下架而被当前状态过滤隐藏，界面明确说明隐藏数量，不只显示骨架屏。

同一饰品命中多行只计一件。状态筛选只作用于平台返回候选及本地已知账号；结果区标注“本次搜索范围”，不宣称列出平台全部下架账号。按所选租期原价比价，营销价独立标注。

| 场景 | 行为 |
|---|---|
| 首次启动 / 每轮检查 | 拉取平台收藏，本地没有的加入本地（来源标「平台」） |
| 在工具内收藏 | 本地新增，同时在平台收藏 |
| 在工具内取消收藏 | 确认框中提供「同时在平台取消收藏」复选框（默认不勾）。不勾则平台保留，本地记为「已移除」，之后同步不再自动加回 |
| 在平台（客户端）取消收藏 | 本地**不删除**，该行标「平台已取消收藏」，操作：「本地也移除」/「重新在平台收藏」 |
| 工具内的「已移除」记录 | 在 P7 可查看并恢复本地收藏；恢复动作不自动写回平台 |

同步写入平台属于对平台的外部写入，仅在用户在工具内执行收藏/取消收藏操作时发生，不做无人触发的写入。

**写回失败**（Q20）：本地操作照常生效；toast「平台收藏同步失败，将在下次同步时重试」；该行标「待同步」，下次同步自动重试，成功后标记消失。

同步必须完整读取所有分页。最新用户意图覆盖旧意图，迟到响应不能把刚取消的收藏重新加回；不完整快照不能据此判断平台取消收藏。

### 6.3 各状态界面

| 状态 | 主体显示 | 按钮 |
|---|---|---|
| 预检中 | 转圈 +「正在检查账号是否可下单…」 | 取消；已发出锁号预检时清理可能的锁后结束 |
| 创建订单中 | 转圈 +「正在创建订单…」 | 无（防止中途中断造成状态不明） |
| 待支付 | 见 §6.1：风险提示条、二维码、金额明细、倒计时、支付方式说明、状态行 | 申请取消并释放账号 |
| 已支付 | 绿色对勾 +「支付成功」+ 订单摘要 + 引导文案「请回到 5E 客户端完成上号」（F4.3） | 完成（关闭） |
| 平台确认超时 | 橙色图标 +「平台已确认支付超时」+ 释放处理结果及冻结风险 | 关闭 / 重新出码（Q10）：处理完本次尝试后才启用，红字「多次未支付可能被平台冻结」 |
| 释放已受理 | 「释放请求已受理，正在核对订单状态」 | 关闭弹窗；后台保留恢复记录，禁止新出码 |
| 创建/释放结果未确认 | 「请到 5E 客户端核对订单」及未结束尝试摘要 | 打开客户端核对说明；用户确认「已支付」或「已无待支付订单」后记为人工处理 |
| 无法下单 / 下单失败 | 红色图标 + 原因 + 建议 | 关闭 / 重试（视原因） |

**关闭行为**：待支付状态下点 ✕、按 Esc 或点「申请取消并释放账号」，均弹确认框：「将申请释放账号；最终订单状态以平台为准。确定继续吗？」→ 确定后隐藏付款码、先查支付状态，已支付则显示成功，仍未支付才申请释放。失败时提示「释放结果未确认，请到 5E 客户端核对」；允许关闭弹窗但保留恢复记录与出码互斥。

**倒计时**：以服务器截止时间和单调时钟为准；剩余 ≤ 60 秒变红。归零立即隐藏付款码并核对平台状态，不根据本地时间宣称订单已关闭。

**支付状态**：待支付期间自动轮询，共享全局限速预算；默认最短间隔 3 秒。休眠恢复立即排入状态核对。已知支付 ID 的结果核对最多持续 5 分钟，仍无法确认时进入客户端核对流程。

**窗口约束**：待支付时弹窗不可被主窗口其他操作遮挡；从预检开始到本次尝试处理完成均占用全局互斥，重复入口定位现有尝试，不创建第二笔订单。

| 原因 | 文案 | 可重试 |
|---|---|---|

| 账号已下架 | 「该账号已下架」 | 否 |

| 超出可下单范围 | 「超出可下单范围，请调整时长」+ 编辑预设入口 | 改预设后 |
| 登录态失效 | 走 §2.4 失效流程 | 读取后 |
| 读取阶段网络错误 | 「读取失败，请重试」 | 只读请求按预算重试 |
| 创建响应丢失 | 「创建结果确认中，请到客户端核对」 | 禁止重发创建 |

- 同一账号在一次「可租」期间只通知一次；回到不可租再变可租时重新通知。
- 首次运行/导入/重新开启单条监测只建立基线；读取失败再恢复可租不重复通知，休眠和重启保留通知周期。
- **同一轮检查有多个账号变为可租时，合并为一条**（Q14）：标题「N 个收藏账号可租了」，正文列出前 3 个编号，按钮仅「查看」→ 打开 P3 并过滤为「可租」；合并通知上不提供一键出码。
- 可在 P7 关闭通知或关闭提示音。

### 7.2 系统托盘

| 元素 | 说明 |
|---|---|
| 图标 | 正常 / 监测暂停（灰）/ 异常（橙点）三态；角标显示当前可租的收藏数，为 0 时不显示（Q11） |
| 悬停提示 | 「饰品驿站助手 · 监测中 A/B 可租」，A/B 口径同底部状态栏；角标另统计所有本地收藏的可租数 |
| 左键单击 | 显示/隐藏主窗口 |
| 右键菜单 | 打开主窗口 · 暂停监测 / 恢复监测 · 退出 |

**关闭主窗口**：默认最小化到托盘继续监测；首次关闭时弹一次提示「已最小化到托盘，监测仍在运行」。关闭行为可在 P7 修改。

**退出**：若存在未结束尝试，先提示「退出前将申请清理当前订单；未确认结果将在下次启动时恢复」并要求确认。清理最多等待 15 秒，保存恢复记录后退出；已支付订单不解锁。
