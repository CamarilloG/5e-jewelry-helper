# 饰品驿站助手 1.0.2 版本说明

> 2026-11-08 · Windows x64 · NSIS 当前用户安装 · **未签名** · 可覆盖安装 1.0.0 / 1.0.1，业务数据保留

## 变化

- **搜索与筛选提速（三类证据 + 快速路径 + 成本规划）**：
  - 词典按可搜性（`queryable`）、精确性（`precision`）、覆盖完整性（`coverage`）分别记录真实平台实测证据、日期与规则版本（`2026.11.08-1`）。
  - 不填皮肤且所选类别全部通过精确性与覆盖完整性认证的条件行，可直接用平台搜索证据判定（`evidence='search'`），免去逐账号拉取完整库存；卡片显示「类别条件匹配，库存详情按需加载」，打开详情时再按需补齐命中件数与清单。
  - 「任意手套」自动展开为「手套 ∪ 裹手」并集；按预期请求成本选择快速路径或最小必要候选源，不再用未完成或缺失页集合做硬交集排除。
- **逐页流式输出与「已匹配，状态待确认」分组**：
  - 候选分页到达即刻开始核验并推送首条匹配结果，不再等待全部搜索页翻完。
  - 默认排序改为「价格↑」；默认「仅可租」过滤上方新增可折叠的「已匹配，状态待确认」分组（默认展开），展示库存或搜索证据已匹配、但实时租用状态尚在确认或来自历史快照的账号；状态确认可租后自动移入「仅可租」列表，同时提示已隐藏的租赁中/已下架数量。
- **5 分钟分页搜索缓存与「刷新最新」**：
  - 同一用户、租期、用券条件、关键词与规则版本下的搜索分页在 5 分钟内复用，未完成分页只补拉缺失页；结果顶栏显示候选快照时间并提供「刷新最新」按钮。
- **本地缓存优先与独立「本地匹配」入口**：
  - 筛选启动时先在当前用户作用域内按账号增量合并上次结果，复核不通过立即移除，请求失败保留并标注「未能复核」。
  - 新增独立于在线登录态的「本地匹配」按钮（支持在线后断网及离线冷启动按 `lastProfileId` 恢复当前用户本地缓存），离线或过期结果统一标注为历史/待核验，不计入实时可租。
  - 支持价格收紧/放宽、用券切换、租期切换等小条件变化的本地快速复用，以及「库存匹配层 + 查询结果层」两层缓存与同账号在途请求合并。
- **收藏监测 3×3 饰品宫格与后台去重补读**：
  - 收藏页每条收藏固定单行布局，左侧单张缩略图升级为 3×3 宫格（按「刀、手套、主战武器（步枪+狙击步枪）各取估价前 2 件，其余按估价降序补满 9 格」选图），鼠标悬停显示饰品名称、磨损与估价。
  - 完整库存生成的宫格摘要（`summaryVersion: 2`）不会被后续常规同步或监测轮次的展示位摘要覆盖降级。
  - 仅含展示位的收藏在进入收藏页时以最低优先级（`Priority.BACKGROUND`）后台去重补读完整库存，共用全局 30 次/分钟限速队列，并在支付出码进行中、退出或身份切换时自动暂停。
- **任务完整性与失败页重试**：
  - 区分「扫描结束」与「覆盖完整」，缺页、重复页、提前空页、200 页截断、候选来源不可用或失败账号未重试时明确标注 `partialReasons`，支持对失败搜索页与失败账号一并重试。

## 修复

- **修复「格洛克」「加利尔」「M4A1 消音版」线上零结果与漏召回问题**：
  - 真实平台搜「格洛克」「加利尔」「M4A1消音版」及带空格的「M9 刺刀」「格洛克 18 型」均返回 `total=0`。1.0.2 已将搜索主词修正为 `格洛克18型`、`加利尔AR`、`M4A1`、`M9刺刀`。
  - 实测发现 `格洛克18型` 与 `加利尔AR` 在平台上虽精确但存在漏召回（`coverage='partial'`），已将其排除在免读库存快速路径之外，并在零结果或覆盖不完整时自动回退到可信必要条件或空关键词全量浏览 + 完整库存确认，解决了 1.0.1 内置方案在真实平台上因「格洛克」返回 0 而误判空结果的缺陷。
- **修复默认方案漏掉真实命中账号的问题（端到端实测发现）**：覆盖不完整的类别（如「格洛克 18 型」）不再参与搜索结果求交，改由完整库存确认；按请求成本决定是否继续翻页；候选阶段对必中账号提前确认，真实平台首个可租结果从约 215 秒提前到约 22 秒。详见 [验证记录](验证记录.md) §9.4。
- **修复候选阶段停止后继续重拉已成功页的问题**：保存每个候选源的分页游标与待确认队列，在候选阶段或确认阶段停止后点击「继续」均从断点恢复。
- **修复程序退出时 `Error: Tray is destroyed` 弹窗**：退出清理阶段主动取消待触发的状态/收藏定时器并校验托盘销毁状态，防止托盘销毁后迟到状态事件触发主进程异常。

## 兼容与迁移

- **库存缓存有效期默认值迁移（Settings Schema v2）**：全新安装默认库存缓存有效期设为 **6 小时（`6H`）**；从 1.0.0 / 1.0.1 升级时保留用户已保存的有效设置（`SESSION` / `1H` / `6H` / `1D`）；旧配置文件缺字段或值非法时回退为 `1H`。
- **收藏摘要兼容**：自动兼容 1.0.0 / 1.0.1 的 v1 单图摘要，确认完整库存为空时清空旧展示位图片且不回退。
