## 4. 浏览器交互验收（离线预览 + 虚拟平台）

- ego-browser：示例条件“蝴蝶刀 + 多普勒”完成筛选（11 个符合，限速等待在结果区与底栏可见）→ 打开详情（抽屉 440px、库存 8 件命中 3 件）→ 勾选协议 → 一键出码进入待支付（¥15.00、倒计时 03:01、付款码图片）→ Esc 弹出“将申请释放账号；最终订单状态以平台为准”→ 确认后显示“释放请求已受理”而非“已取消”→ 平台确认超时后结束（创建 1、释放 1）。
- 通知链路：账号变可租 → 通知含“先到先得，工具不代抢”→ 出码动作打开预设编辑框 → 保存并出码 → 支付成功、未调用解锁；重放同一 nonce 未产生新创建。
- 内置浏览器截图：1440×900 的 P1 结果卡片与详情抽屉、1200×760 的 P3 与抽屉布局无溢出。
- 验收中发现并修复：焦点不在抽屉内时 Esc 不关闭抽屉；从卡片收藏的账号缺缩略图（`get_info` 不返回展示位）；结果区补充“当前显示 N 个”。
- 限制：ego-browser 窗口处于最小化，截图被拒，视觉截图改用内置浏览器；语义检查均用 ego-browser 完成。截图存放于 Git 忽略的 `.validation/ui-acceptance/`。
