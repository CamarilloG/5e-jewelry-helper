# 饰品驿站助手（5e-jewelry-helper）

5E 对战平台「饰品驿站」的第三方 Windows 桌面助手：按饰品组合条件筛选可租账号、收藏监测并在空闲时提醒、由你手动点击后半自动出码。

> **风险声明**：本工具与 5E 对战平台无关，调用的是平台非公开接口，平台可能随时变更或封堵，使用产生的风险由你自行承担。工具只做提醒和手动触发：**不自动锁单、不自动抢单、不代为支付、不托管支付凭证**；付款由你本人扫码完成，上号与下号回到 5E 客户端完成。

## 运行前提

- Windows 10 22H2 或 Windows 11，x64。
- 已安装 5E 对战平台客户端，并且**在客户端里登录过**。助手只读取本机客户端已有的登录态，不会自行登录，不会把客户端挤下线。

## 安装与卸载

1. 从 [GitHub Releases](https://github.com/CamarilloG/5e-jewelry-helper/releases) 下载 `JewelryHelper-Setup-<版本>-x64.exe`，用同目录的 `SHA256SUMS.txt` 核对校验和。
2. 安装包**未签名**，Windows 可能提示“未知发布者”，确认来源后继续即可。安装到当前用户目录，不需要管理员权限，路径可以包含中文和空格。
3. 卸载：在“设置 → 应用”中卸载。缓存与日志会删除；收藏、下单预设、常用方案和订单恢复记录**默认保留**，卸载时会询问是否一并删除。覆盖安装升级会保留全部业务数据。

本机数据位置：`%LOCALAPPDATA%\JewelryHelper\data\app.db`。

## 使用

- **首次启动**：自动读取客户端登录态并向 5E 官方接口确认身份。读不到时会提示安装/登录客户端或手动指定 `Local Storage\leveldb` 目录。凭证不会显示在任何位置、不写入日志。
- **筛选**：每一行描述“同一件饰品”（如 蝴蝶刀 + 多普勒），多行之间取交集；可叠加租期与价格。含饰品条件时会逐个读取完整库存确认，进度和限速等待显示在结果区与底栏，可随时停止/继续。
- **收藏监测**：工具内收藏会同步到平台；在平台收藏的账号会自动导入（只增不删）。默认每 60 秒检查一次，首轮只建立基线；账号从“租赁中/已下架”变为“可租”时弹出 Windows 通知。
- **一键出码**：首次需在账号详情下单区勾选协议与占号风险。之后点击「一键出码」会**立即创建订单并占用账号**，弹出平台付款码与倒计时。请在倒计时内用手机扫码付款；多次未支付可能被平台冻结。付款成功后回到 5E 客户端上号。
- **取消与异常**：待支付时关闭弹窗、按 Esc 或点「申请取消并释放账号」都会先确认。释放请求被受理不等于订单已取消，助手会继续核对；结果无法确认时会提示你到客户端核对，并在你确认前阻止新的出码，绝不重复创建订单。
- **请求设置**：所有功能共用每分钟 30 次的请求上限（可在设置中调整，调高有被平台限制的风险）。
- **托盘**：关闭窗口默认最小化到托盘继续监测；托盘图标角标为当前可租的收藏数。退出请用托盘菜单“退出”。

## 故障恢复

| 情况 | 处理 |
|---|---|
| 顶部提示“登录态失效” | 在 5E 客户端重新登录，再点“重新读取” |
| 提示“平台接口可能已变更” | 平台改了接口，部分功能暂不可用；请关注新版本 |
| 出码弹窗提示到客户端核对 | 打开 5E 客户端订单页核对，再在弹窗中选择“已支付”或“已无待支付订单” |
| 本地数据库不可用 | 迁移失败时会自动恢复备份并阻止写入；可在“设置 → 导出诊断信息”后反馈（导出内容已脱敏） |

检查更新只会在你点击时打开 GitHub 发布页，助手不会后台联网检查或自动下载，也不回传任何数据。

```bash
npm ci

```

```bash

npm run build:auth
```

```bash
npm run package:win
```

`npm run preview:offline` 会在 `http://127.0.0.1:5178/` 启动离线预览：真实的主进程业务服务 + 虚拟平台数据，不读取真实登录态、不连接平台，用于界面与流程验收。默认测试与 CI 同样只使用虚拟数据。

规范文档见 [docs/README.md](docs/README.md)，第一期验收记录见 [docs/验收记录.md](docs/验收记录.md)。
